# Yusuf Sahin — Academic Homepage

A compact academic homepage inspired by Jon Barron's research site. It is
configured as a fully static export for the `yusufsahin99.github.io`
repository.

## Local preview

```bash
npm install
npm run dev
```

## Static GitHub Pages build

```bash
npm run build
```

The publishable static site is generated in `dist/client`. The GitHub Actions
workflow builds and publishes that directory whenever `main` is updated.
